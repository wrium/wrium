Reactive state

Wrap a value in ref() to make it reactive, then read and write it through .value from JavaScript. Inside a template, Wrium unwraps it automatically.

List rendering

Use v-for to render a list from an array:

<ul>
    <li v-for="item in items" :key="item.id">{{ item.text }}</li>
</ul>
